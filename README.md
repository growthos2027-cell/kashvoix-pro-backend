# 🚀 GrowthOS KashVoix Pro — Backend API

API Backend pour la solution SaaS **GrowthOS KashVoix Pro**, l'application mobile de gestion financière et comptable pilotée par la voix avec architecture **Offline-First**.

---

## 🛠️ Stack Technique

- **Runtime :** Node.js (v18+)
- **Framework Web :** Express.js
- **ORM :** Prisma ORM
- **Base de Données :** PostgreSQL (Supabase / Render)
- **Authentification :** JWT (JSON Web Tokens)
- **Architecture :** Offline-First avec protocole de synchronisation bidirectionnel (Last-Write-Wins)

---

## 📌 Fonctionnalités Clés du Backend

- 🟢 **Protocole de Synchronisation (`POST /api/v1/sync`) :** Gestion Push/Pull des données financières créées ou modifiées hors-ligne.
- 🔒 **Contrôle d'Accès Linguistique (`PATCH /api/v1/user/language`) :** Restriction du plan Gratuit au français et déblocage du multilinguisme pour les abonnés Pro/Entreprise.
- 💳 **Webhooks de Paiement :** Intégration pour la validation automatique des abonnements Mobile Money (Orange Money, MTN, Wave) et Stripe.
